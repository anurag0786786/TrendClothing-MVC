# TrendClothing-MVC

An ASP.NET Core MVC e-commerce web application built for learning, resume, and demo purposes.

## 🔧 Tech Stack
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server (LocalDB)
- Razor Pages
- Bootstrap
- Stripe Payment Gateway (test mode)
- Authentication (Google & Facebook)

## ✨ Features
- User authentication & authorization
- Product listing & categories
- Shopping cart & checkout
- Stripe payment integration
- Email notifications
- Admin panel (product management)

## 🚀 How to Run Locally
1. Clone the repository
2. Update `appsettings.Development.json` with your own credentials
3. Run the project using Visual Studio
